# Map Georeferencer

A Python toolkit for georeferencing raster maps and imagery from ground control points, with transformation accuracy assessment and GeoTIFF export.

## Status

🚧 Early development

## Planned capabilities

- Read raster images and ground control points
- Estimate georeferencing transformations
- Warp images into a target coordinate reference system
- Export georeferenced GeoTIFF files
- Calculate residuals and RMSE
- Generate transformation accuracy reports

## Tech stack

`Python` · `Rasterio` · `GDAL` · `PyProj` · `NumPy`
